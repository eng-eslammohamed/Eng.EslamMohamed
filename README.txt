GitHub Pages portfolio files

1. Upload index.html and Eslam_Mohamed_IT_Engineering_Portfolio.pdf to the root of your GitHub repository.
2. Keep the repository public.
3. Open Settings > Pages. Choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the site.

The website links to the PDF using the relative filename, so keep both files in the repository root.
